# Fontes — Gaia

Fontes web (woff2 + woff) do par tipográfico do brief. Ver `CONTEXT.md` §5.

- **Títulos → Sentient** (serifada). Family CSS: `--font-title`.
- **Corpo → Clash Display**. Family CSS: `--font-body`.

Variáveis disponíveis: `*-Variable.woff2` (Sentient tem `-VariableItalic` também).
Carregar via `next/font/local` quando o scaffold Next existir.

Licenças (Fontshare / Indian Type Foundry) nos zips originais em `~/Downloads/`.
